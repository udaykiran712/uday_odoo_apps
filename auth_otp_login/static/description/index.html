Flow

How it works

Four steps, no password.

Request
Click “Login with Email OTP” on the normal Odoo login page and enter your email address.
Receive
A designed email arrives with a 6-digit code — valid for 10 minutes and usable once (defaults).
Enter
Type or paste the code into auto-advancing boxes. Resend is available after a short, visible countdown.
Sign in
You’re in. Users with two-factor enabled are then asked for their authenticator code.

Security

Security, in detail

What actually happens under the hood.

✓Cryptographically secure codes
Generated with Python’s secrets module — not a predictable random generator.
✓Never stored in plain text
Only a salted SHA-256 digest is saved, with a fresh random salt for every code.
✓Constant-time comparison
Codes are compared with hmac.compare_digest, which doesn’t leak timing information.
✓Single-use and short-lived
Valid for 10 minutes by default and only once; requesting a new code invalidates the previous one.
✓Brute-force protection
A per-code attempt limit (5 by default). The code locks the moment the last attempt is used.
✓Anti-spam rate limits
A resend cooldown plus a rolling hourly cap per address — including unknown and blocked addresses.
✓No account enumeration
The login page answers identically for existing, unknown and blocked emails; only the inbox owner is told more.
✓Works with two-factor
OTP never bypasses Odoo’s 2FA: users who have it enabled still enter their authenticator code.
✓Group policy enforced twice
Blocked groups are checked when a code is requested and again when it is verified.
✓Automatic cleanup
Used and expired codes and request logs are purged automatically after 30 days.

FAQ

Questions, answered

Click a question to expand it.

Does this replace password login?
No. Password login keeps working exactly as before. “Login with Email OTP” is an extra option on the same login page.
What happens if someone types an email that has no account?
The page shows the same message it shows for any address, so it can’t be used to find out which emails exist. The typed address itself receives a “we couldn’t find an account” email, rate-limited like everything else.
What if a user is in a blocked group?
No code is issued. They receive an email explaining that OTP isn’t available for their account and that they should use their password. The on-screen message is identical.
Can I allow OTP for portal users only?
Yes. Add the groups that should not use OTP — for example Internal User — to “Who is blocked from OTP login”. Leave it empty to allow everyone.
Are the codes stored in the database?
Only as a salted SHA-256 digest. The plain code exists briefly in memory to be placed in the email and is never stored or logged.
What data does it store — and does anything leave my server?
For each code: the user, the login that was typed, a random salt, the salted hash of the code, its expiry, the attempt count and its state. For addresses with no account, and for users in a blocked group: the typed email and a timestamp, used for rate limiting and the dashboard. All of it stays in your own Odoo database and is deleted automatically after 30 days. The module makes no outbound network requests of its own — the only thing that leaves your server is the email itself, sent through your own outgoing mail server.
Does it work with Odoo’s two-factor authentication?
Yes, and it never bypasses it. A user with 2FA enabled enters the OTP and is then asked for their authenticator code before they are logged in.
Why is the “Resend code” button disabled?
Each address has a short cooldown (30 seconds by default) and an hourly cap (5 by default). The button shows a live countdown, and both limits are configurable.
No email arrives — what should I check?
That your outgoing mail server works, that the company has an email address (it is used as the sender), and the spam folder. In developer mode, Settings → Technical → Emails shows whether the message was queued or failed.
Does it support multiple companies?
Yes. Settings are stored per company, and each user’s own company decides their limits and sender address.
How long is OTP data kept?
Codes and request logs are purged automatically after 30 days.

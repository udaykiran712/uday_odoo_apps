Features

Why this module

Turn grey placeholder avatars into a vibrant, recognizable address book — automatically and safely.

Smart domain extraction
Extracts and normalizes domains from the partner’s website (stripping http://, https://, www., ports, and URL paths) or falls back to their email domain (@domain.com).
1-Click API “Test Connection”
Verify your Logo.dev Publishable Key (pk_...) right inside Settings → General Settings → Contacts. Auto-saves your key and shows a live green connection toast.
Dual execution modes
Run in non-blocking Background Cron Mode (every 15 minutes in batches of 50) or enable Immediate Logo Fetch in Settings to enrich contacts the instant they are saved.
One-click “Fetch Logo” button
Adds a native Fetch Logo stat button directly inside the Partner Form button box whenever a website or email is present — with instant toast feedback and automatic view reload.
Bulk server action
Select dozens or hundreds of contacts in the Partner List view and click Action → Fetch Partner Logos to enrich existing records in one batch with a live summary toast.
404 infinite-loop protection
Tracks lookup status (pending, fetched, not_found, failed) and clears the pending flag on HTTP 404 responses so unknown domains are never retried endlessly.
Preserves existing custom avatars
Automatic create(), write(), and cron hooks only fetch a logo when image_1920 is empty — never overwriting photos uploaded manually by your team.
Auto-resized Odoo thumbnails
Writes directly to Odoo’s native image_1920 field on res.partner, so image.mixin automatically generates image_1024, image_512, image_256, and avatar_128.

Flow

How it works

Four automated steps from domain parsing to high-resolution avatar generation.

1. Extract
Reads website first (or falls back to email) and strips protocols, www., ports, and paths to isolate the clean domain.
2. Verify & Query
Uses your verified pk_... key to call https://img.logo.dev/{domain} with format=png, size=200, and a 10s timeout.
3. Enrich
Base64-encodes the PNG binary into image_1920, automatically computing all Odoo avatar thumbnails.
4. Track Status
Sets logo_fetch_status to fetched, not_found, or failed and clears logo_fetch_pending.
Architecture

Reliability, in detail

Engineered for real production databases — what actually happens under the hood.

✓1-Click API connection tester
Built-in action_test_logo_dev_connection() in Settings auto-persists your typed key and tests live connectivity against img.logo.dev.
✓Recursion-safe context guard
All internal updates use with_context(skip_logo_fetch=True) so writing image_1920 never re-triggers write() recursively.
✓Smart 404 handling
When Logo.dev returns HTTP 404, the partner is marked not_found and logo_fetch_pending=False to prevent endless cron retries.
✓Bounded 50-record cron batches
The 15-minute scheduled action processes up to 50 pending partners per run so worker threads never hit timeouts on large imports.
✓Multi-record & batch safe
Uses @api.model_create_multi and iterates recordsets safely in write() and action_fetch_logo() without singleton errors.
✓Instant UI toast & soft reload
Manual fetches return a display_notification client action chained with soft_reload so the new logo appears immediately.

FAQ

Questions, answered

Click any question below to expand the answer.

How can I verify that my Logo.dev API key is working before enriching partners?
In Settings → General Settings → Contacts, paste your pk_... key and click the Test Connection button right underneath the input field. It automatically persists your key, performs a live test request against img.logo.dev, and shows a green “Connection Successful” toast notification.
Which fields are mandatory on a partner to fetch a logo?
Alongside the partner’s Name, you only need either a Website (e.g., starbucks.com or https://www.stripe.com) or an Email containing a valid domain (e.g., info@starbucks.com or user@gmail.com). Website is checked first; if empty, the email domain is used.
Which Logo.dev key should I paste — Publishable (pk_) or Secret (sk_)?
Use your Publishable Key (starts with pk_...). Logo.dev’s image CDN endpoint (https://img.logo.dev/{domain}?token=pk_...) is designed specifically for publishable tokens.
Will automatic enrichment overwrite a photo I already uploaded?
No. Automatic enrichment on create(), write(), and the 15-minute cron job strictly checks if not partner.image_1920 first. Only clicking the manual Fetch Logo button or running the bulk action intentionally refreshes the image.
What happens if a company’s domain has no logo on Logo.dev (HTTP 404)?
The module sets logo_fetch_status = 'not_found' and logo_fetch_pending = False. This ensures the background cron job never wastes API calls retrying missing domains in an infinite loop.
How do I enrich hundreds of existing partners at once?
Switch to the Contacts List View, select the contacts you want to enrich, and click Action → Fetch Partner Logos. Odoo will fetch their logos and show a summary toast notification.
